As an engineering manager, my team kept Facebook's main web codebase buildable and deployable. We built and ran the integration and CI/CD systems that let about 10,000 engineers land dozens of commits per minute to a 100-million-line monorepo, built a novel E2E testing platform, and scaled code generation tools and practices in Facebook's specialized languages and runtimes.
